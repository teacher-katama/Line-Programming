📘 第一章 線性規劃 · 系統化知識導覽

本章涵蓋從平面幾何、二元一次不等式、半平面，一直到線性規劃的兩大求解利器：「平行線法」與「頂點法」。

1. 平行直線系 (Parallel Lines)

在坐標平面上，斜率相等的兩相異直線必互相平行。平移直線只會改變位置，不會改變直線的斜率。

  • 直線一般式：$L: ax + by + c = 0$ ($b \ne 0$)，斜率為 $m = -\frac{a}{b}$。
  • 平行直線系：保持 $x, y$ 的係數比不變，僅改變常數項 $c$，即可得到一組互相平行的直線族 $ax + by = k$。
  • 截距變化：當 $a, b > 0$ 時，$k$ 越大，直線的 $x$ 截距與 $y$ 截距均隨之增大，直線往右上方平移。
例題重點：平移直線 $L_0: x-y=0$ 向右平移 $h$ 單位得 $x-y=h$；向左平移得 $x-y=-h$。

2. 二元一次不等式與半平面

任意一條直線 $ax + by + c = 0$ 都會將坐標平面切割為左右或上下的兩個「半平面」。

  • 實線與虛線：不等式包含等號（$\ge, \le$）時邊界包含在內，畫實線；不包含等號（$>, <$）時畫虛線。
  • 檢驗點法：選取一個不在直線上的點（首選原點 $(0,0)$ 或 $(1,0)$）代入不等式。若符合，則該點所在的半平面即為解的區域！
  • 聯立不等式：多個不等式的交集，即為各自半平面的重疊區域。
公式口訣：代入原點 $(0,0)$，若不等式成立則取「含原點之半平面」，反之取「不含原點之半平面」。

3. 線性規劃兩大解題法

當目標函數為一次函數 $P(x,y) = ax + by$，且限制條件均為一次不等式時，稱為線性規劃。

  • 可行解與可行解區域：滿足所有限制條件的數對 $(x,y)$ 構成可行解區域（通常為凸多邊形）。
  • 平行線法：令 $ax + by = k$，在可行解區域內平行平移此直線，找尋最後接觸區域的切點。
  • 頂點法（極值定理）：有界凸多邊形的可行解區域，目標函數的最大值或最小值必在頂點（或邊界）出現！只需算出所有交點坐標代入比較即可。
解題三部曲：1. 畫出可行解區域 → 2. 求出所有頂點坐標 → 3. 代入目標函數比較大小。

4. 生活與商業決策應用

現實生活中的資源最佳配置問題（如原料調配、廢棄物限制、利潤最大化、生產成本最低化）。

  • 精油提煉（例題 5）：在成本 $\le 240$ 萬、廢棄物 $\le 750$ kg 的雙重限制下，提煉出最大精油量約 297.14 kg。
  • 工廠訂單生產（例題 6）：在達成客戶金屬純度標準下，透過甲、乙工廠排程使總成本降至最低。
  • 隱含條件不可漏：實際生活問題中，原料量、產量、工時均不可為負，務必列出隱含條件 $x \ge 0, y \ge 0$。
素養關鍵：先設變數 $(x, y)$，明確列出限制聯立式，再定義目標函數 $P(x,y)$。

5. 數學史專欄：諾貝爾獎榮譽

線性規劃最早於 1920～1930 年代由前蘇聯數學家坎拓羅維奇（Leonid Kantorovich）與經濟學家李安鐵夫（Wassily Leontief）提出。

  • 坎拓羅維奇 (1912～1986)：首創將線性不等式應用於生產排程，榮獲 1975 年諾貝爾經濟學獎。
  • 李安鐵夫 (1905～1999)：建立「投入產出模型（Input-Output Model）」，榮獲 1973 年諾貝爾經濟學獎。
  • 現代發展：結合現代電腦演算法（單純形法 Simplex Method、內點法），廣泛應用於全球航線調度、物流供應鏈與晶片設計。

基本題 1 二元一次聯立不等式繪圖：3x + 2y - 12 ≤ 0 且 x + y - 2 > 0
▼

題目：在坐標平面上畫出聯立不等式 $\begin{cases} 3x + 2y - 12 \le 0 \\ x + y - 2 > 0 \end{cases}$ 的圖形。

詳細題解：
1. 畫直線 $L_1: 3x + 2y - 12 = 0$，與兩軸交點為 $(4, 0)$ 和 $(0, 6)$。因包含等號，以實線繪製。代入原點 $(0,0)$ 得 $-12 \le 0$ 符合，故取含原點的一側。
2. 畫直線 $L_2: x + y - 2 = 0$，與兩軸交點為 $(2, 0)$ 和 $(0, 2)$。因不包含等號，以虛線繪製。代入原點 $(0,0)$ 得 $-2 > 0$ 不合，故取不含原點的一側。
3. 取兩半平面的共同交集，即為直線 $L_2$ 之右上方與直線 $L_1$ 之左下方所夾區域。
基本題 2 從三角形區域圖形逆推二元一次聯立不等式
▼

題目：解集合為頂點 $(0,1), (3,2), (6,0)$ 所圍成之三角形區域，試寫出此聯立不等式。

詳細題解：
1. 求過 $(0,1)$ 與 $(3,2)$ 之直線：斜率 $m = \frac{2-1}{3-0} = \frac{1}{3} \implies x - 3y + 3 = 0$。三角形內部點 $(3,1)$ 代入得 $3 - 3 + 3 = 3 \ge 0 \implies x - 3y + 3 \ge 0$。
2. 求過 $(3,2)$ 與 $(6,0)$ 之直線：斜率 $m = \frac{0-2}{6-3} = -\frac{2}{3} \implies 2x + 3y - 12 = 0$。代入內部點得 $2(3) + 3(1) - 12 = -3 \le 0 \implies 2x + 3y - 12 \le 0$。
3. 求過 $(0,1)$ 與 $(6,0)$ 之直線：斜率 $m = -\frac{1}{6} \implies x + 6y - 6 = 0$。內部點代入得 $x + 6y - 6 \ge 0$。
答案：$\begin{cases} x - 3y + 3 \ge 0 \\ 2x + 3y - 12 \le 0 \\ x + 6y - 6 \ge 0 \end{cases}$
基本題 3 平行線之平移量計算 (L1: 2x - y = 1, L2: 2x - y = 3)
▼

題目：已知 $L_1: 2x - y = 1$，$L_2: 2x - y = 3$。(1) 若 $L_1$ 向右平移 $k$ 單位得 $L_2$，則 $k$ 值為何？ (2) 若 $L_2$ 向上平移 $h$ 單位得 $L_1$，則 $h$ 值為何？

詳細題解：
(1) 向右平移 $k$ 單位，以 $(x - k)$ 代入 $L_1$：
$2(x - k) - y = 1 \implies 2x - y = 1 + 2k$。對照 $L_2: 2x - y = 3 \implies 1 + 2k = 3 \implies \mathbf{k = 1}$。

(2) 向上平移 $h$ 單位，以 $(y - h)$ 代入 $L_2$：
$2x - (y - h) = 3 \implies 2x - y = 3 - h$。對照 $L_1: 2x - y = 1 \implies 3 - h = 1 \implies \mathbf{h = 2}$。
基本題 4 四點 A, B, C, D 代入目標函數 x - 2y = k 哪一點所得 k 值最大？
▼

題目：給定點 $A, B, C, D$ 及直線 $L: x - 2y = 0$，哪一點代入 $x - 2y = k$ 所得 $k$ 值最大？

幾何直觀判定：
直線方程式為 $x - 2y = k$，斜率為 $\frac{1}{2}$，$x$ 截距為 $k$。
因此，當直線平行向右下方平移時，$x$ 截距 $k$ 越大！
觀察四點相對位置，點 D 位在最右下方，故點 D 代入時能得到最大的 $k$ 值。
基本題 5 整數解（格子點）計數問題 (3x + 2y ≤ 6, x ≥ 0, y ≥ 0)
▼

題目：求滿足 $3x + 2y \le 6, x \ge 0, y \ge 0$ 的整數解 $(x, y)$ 共有幾組？

詳細枚舉：
• 當 $x = 0$ 時：$2y \le 6 \implies y \in \{0, 1, 2, 3\}$（4 組）
• 當 $x = 1$ 時：$2y \le 3 \implies y \in \{0, 1\}$（2 組）
• 當 $x = 2$ 時：$2y \le 0 \implies y = 0$（1 組）
• 當 $x \ge 3$ 時：無非負整數解。
全部共有 $4 + 2 + 1 =$ 7 組整數解。
進階題 6 符號分析與常數項大小判定 (L: ax + by = c, 已知 a < 0)
▼

題目：$L_1: ax+by=c_1, L_2: ax+by=c_2, L_3: ax+by=c_3$，已知 $a < 0$ 且由左至右分別為 $L_3, L_2, L_1$。(1) $b$ 為正或負？ (2) 比較 $c_1, c_2, c_3$ 大小。

詳細題解：
(1) 觀察圖形，直線呈右上至左下傾斜，斜率 $m > 0$。
斜率公式 $m = -\frac{a}{b}$。因 $a < 0 \implies -a > 0$，要使 $m > 0$，分母必須為正數，故 $\mathbf{b > 0}$。

(2) 直線與 $x$ 軸之交點為 $(\frac{c}{a}, 0)$。由圖可知由左而右 $x$ 截距依次增大：
$\frac{c_3}{a} < \frac{c_2}{a} < \frac{c_1}{a}$。
因已知 $a < 0$，不等式同乘以負數 $a$ 需變號，得：
$\mathbf{c_3 > c_2 > c_1}$（即 $c_1 < c_2 < c_3$）。
進階題 7 正六邊形 ABCDEF 頂點求 3x - 2y = k 最大值
▼

題目：正六邊形 $ABCDEF$ 底邊在 x 軸上，$L: 3x - 2y - k = 0$，問通過哪一個頂點時可使 $k$ 值最大？

斜率平移法：
直線為 $3x - 2y = k \implies y = \frac{3}{2}x - \frac{k}{2}$，斜率為 $1.5$。
$k = 3x - 2y$，要使 $k$ 最大，需讓 $x$ 盡量大且 $y$ 盡量小（即往平面最右下方移動）。
檢視正六邊形各頂點位置，頂點 B（位於 x 軸正向最右下端點）能使 $k$ 達到最大值。
進階題 8 兩貨倉至兩工廠之經典運輸問題 (最低運費最佳化)
▼

題目：貨倉甲存50噸、乙存60噸；A工廠訂購40噸、B工廠訂購50噸。甲→A運費500元、甲→B 600元；乙→A 650元、乙→B 700元。如何調度運費最省？

建模與線性規劃：
設貨倉甲運送 $x$ 噸至 A 工廠，$y$ 噸至 B 工廠。則：
• 乙運送 $(40 - x)$ 噸至 A 工廠，$(50 - y)$ 噸至 B 工廠。
• 甲總量：$x + y \le 50$ 且 $x \ge 0, y \ge 0$。
• 乙總量：$(40 - x) + (50 - y) \le 60 \implies x + y \ge 30$。
• 需求上限：$x \le 40, y \le 50$。
總運費 $C = 500x + 600y + 650(40 - x) + 700(50 - y) = 61000 - (150x + 100y)$。
要使運費 $C$ 最小，需使 $150x + 100y$ 達到最大。
可行解頂點有 $(40, 0), (40, 10), (0, 50), (0, 30), (30, 0)$。
在頂點 $(40, 10)$ 時，$150(40) + 100(10) = 7000$ 為最大，此時運費為 $61000 - 7000 =$ 54,000 元。
調度策略：甲送 A 40噸、甲送 B 10噸；乙送 A 0噸、乙送 B 40噸。
素養題 9 多重最佳解（兩端點同時達最大值求參數 k）
▼

題目：可行解為三角形 ABC 及其內部，目標函數為 $x + ky$。若在 $(5, 3)$ 與 $(7, 7)$ 同時達到最大值，則 $k$ 值為何？

核心幾何原理：
若目標函數在兩相異頂點同時達到最大值，則連接這兩點的整條邊界線段上的每一點皆為最佳解，此時目標函數的等高線必與該邊界平行！
將兩點坐標代入 $P = x + ky$：
$5 + 3k = 7 + 7k \implies 4k = -2 \implies \mathbf{k = -\frac{1}{2} = -0.5}$。
素養題 10 禽流感防範：雞群飼料營養素最低成本最佳化
▼

題目：營養需求：A ≥ 84, B ≥ 72, C ≥ 60 單位。第1種飼料每kg 5元（含A:7, B:3, C:3）；第2種每kg 4元（含A:2, B:6, C:2）。如何調配使成本最低？

列式與頂點求解：
(1) 限制條件：
• A: $7x + 2y \ge 84$
• B: $3x + 6y \ge 72 \implies x + 2y \ge 24$
• C: $3x + 2y \ge 60$
• $x \ge 0, y \ge 0$
(2) 目標函數：成本 $C = 5x + 4y$ (元)
(3) 頂點求解：
• $(0, 42) \implies C = 168$
• $(6, 21)$［解 $7x+2y=84$ 與 $3x+2y=60$］$\implies C = 5(6) + 4(21) = 114$
• $(18, 3)$［解 $3x+2y=60$ 與 $x+2y=24$］$\implies C = 5(18) + 4(3) = 90 + 12 =$ 102 元 (最低)
• $(24, 0) \implies C = 120$
答案：每天使用第 1 種飼料 18 公斤、第 2 種飼料 3 公斤，最低飼料成本為 102 元。
